## 测试结果

- Node 24.21.0：27 个单元/本地集成测试全部通过；`node scripts/validate.cjs` 输出带源码指纹的结果。
- 实际 rc.2 宿主隔离探针：Creator 工具包含关系、跨 Session 工具/CAS/遗忘、上下文注入、未绑定拒绝、提取队列、官方 Schedule 创建/删除/到期、通知去重和卸载撤权通过。QQ 网络禁用，Sender 为测试替身；不冒充真实收件。
- 隔离真实 LLM：使用现有模型配置及私下暂存的现有模型凭据，单次提取 saved=1 / rejected=0，结果为 uncertain；QQ 凭据未复制。测试目录和凭据不进入 Git。
- 生产 test.5：真实模型写入 → 召回 → 遗忘 → 再查询为空通过。
- 实际回滚到 test.2、Schema 1 后，相同严格烟雾测试通过。
- 再部署 test.3 并额外重启后，相同严格烟雾测试通过；SQLite `integrity_check=ok`。
- 真实通知：一次官方 Schedule 到期，统一 outbox 对每个唯一验收事件各只有一条 sent；进程重启后每个事件记录保持一条。sent 是 API 成功返回，不是手机回执。
- 维护策略校验通过；生产自有插件与交付源码逐文件一致；官方 ASAR SHA 与切换前一致。

首次生产烟雾测试因官方 time-context/runtime-context 被误判为并发输入而失败。这是明确失败结果，没有被当作通过；修正来源分类并新增回归后，重新发出独立请求验收通过。初次隔离模型测试也因缺少模型凭据失败，随后按既有配置完成真实调用。

test.4 另补两项恢复回归：第三次抽取尝试中断会转为 failed，可由 Owner 重试，不会永久卡在 pending；通知泵仅处理当前 Owner 的 conversation，旧 Owner 的待发记录不会发送给新绑定。

test.5 补充模型返回时的身份复核：若等待期间 Session 被撤权，整个任务进入重试路径，保留证据；不能把授权失败吞成普通事实拒绝后清空任务。

## 部署与回滚

部署前确认空闲，在维护锁内停止宿主；最终 184 个文件的离线检查点逐文件校验，包含配置、Session、数据库、依赖包、维护工具及凭据，全部仅留本机。测试包使用新版本文件名，未覆盖旧包。旧 Profile 保留在安装目录的 `data/maintenance/character-profile-before-*`。

生产回滚已实际执行，不只是 mock：旧 Profile、QQ 路由、维护策略和检查点 Schema 1 数据库一起恢复，Schema 2 数据另存。随后恢复 test.3，并完成独立重启验收。回滚时本次新库没有用户新增记忆，只有已遗忘的验收数据。

当前 test.5 的直接回滚目标是保留的 test.4 / Schema 2；此前 test.3 → test.2 / Schema 1 已完成实际演练。需要回滚时，在已审阅的本机安装上设置 `DSH_INSTALL_ROOT` 和 `DSH_CHARACTER_PROJECT`，运行 `scripts/rollback.ps1`。脚本要求宿主空闲、旧文件完整性匹配；恢复对应检查点记忆并把较新库保留在 `data/maintenance/character-deploy/schema2-before-rollback-*`。**回滚会把可见记忆恢复到检查点时间；之后新增记忆需要审阅并恢复，不能只切旧插件继续读写 v2 库。**

后续发布必须新版本打包，不覆盖同版本 tgz。存在 active Schedule 任务时部署门禁拒绝切换，要求先核对任务迁移/恢复；已完成的 inactive 历史记录不会阻塞维护。

## 未完成及剩余风险

- 可选 embedding 混合检索未实现；当前是中文词法检索与重排。没有另装向量模型/外部向量服务。
- 后台整理是新证据驱动、有限候选的保守增量处理；没有全量历史回填、全库自动纠错或自动解决相反事实。冲突保留为待确认。
- Owner 记忆操作已有自然语言工具，但没有新增专用 Memory UI。官方 Schedule 和 Preset 管理界面继续使用。
- 真机手机入站/收件、审批卡按钮回传、QQTK 长任务各异常分支、真实插件热重载压力测试、跨版本 DSH 升级未全覆盖。既有审批代码未改动，不能据此声称新版本审批端到端已重测。
- unknown 投递需要人工核对，避免重复发送；未实现自动服务端回执对账。
- 遗忘是逻辑删除与重新提取屏障，修订/原聊天/备份不是物理擦除。低相似改写仍可能绕过近似屏障。
- 没有自动 Session 轮换、跨机同步、独立 Worker 权限体系、群聊或主动闲聊；本版不把这些既有缺项描述成已实现。
