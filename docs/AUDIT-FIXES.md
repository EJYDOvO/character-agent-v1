## 接口与兼容

- 保留四个运行时插件、Core/Extras、Creator 构建派生、原工具名称与参数；没有修改 QQTK、Identity、QQ Adapter、Schedule、审批和通知实现。
- MemoryStore 新增内部候选迭代接口，分层逻辑负责模式、证据、全局排序和最终预算。查询仍使用 SQLite FTS5；没有引入新检索服务、插件或依赖。
- 继续使用 Schema 3。新信息存于既有 source JSON：形成策略与经 Host 确认的冲突集合摘要；不重命名 namespace、ID，不批量重写旧记忆。旧 Schema 2 的既有迁移及旧数据测试继续通过。
- Assistant 不会猜测旧人格化记录是在何种模式形成的，因此旧记录保守隐藏。不要批量将未知记录改成 Assistant；Character 模式仍能检查、纠错或遗忘它们。general 仍按原授权三元组共享。
- 冲突取舍摘要绑定根作用域、Agent 和模式，摘要不写其他 Agent 的私有 ID。当前候选集合或修订变化后，原确认不再自动解决新冲突。
- 同文去重只影响读取，不自动删除或合并原记录。L3 保留一个代表的 ID/revision，仍可 trace。遗忘屏障会使其他用途的同文副本一并失效，不能通过剩余副本复活。
- 话题状态是有界进程内状态：按作用域/Agent/Session 隔离，最多 256 项、30 分钟失效。重启后等待新的可信输入，不从旧持久 L1 推断当前话题。简单追问只有明确的小型规则，不是完整指代消解。
- 主动 Recall 保留完整记录和默认 2400 字符预算；自动 L2 注入按实际渲染字段约 5000 字符预算；L3 仍为默认 1200、上限 1500 估算 Tokens。没有宣称这些等于整轮精确模型预算。

## 没有伪称修复的设计限制

1. **引用真实不保证推断正确。** 本次没有把词项规则或额外模型调用包装为语义证明；无依据的归纳仍有风险，自动 supported 的含义没有升级为 confirmed。
2. **Self 没有完整任务反馈闭环。** 工具正常返回仍不等于任务成功；真实任务目标、结果判据、反馈归属及多轮学习没有在本轮扩展或完成真实模型验收。
3. **L1 仍是可信证据记录。** 未新增多轮事件聚合、全库整理游标或把 Compaction 摘要直接当事实。最近 40 条的巩固窗口限制仍存在。
4. **整条证据退休策略保留。** 遗忘一项可能使同消息其他事实失效；没有为了提高召回率放松屏障，也没有新增事实片段级恢复能力。任意语义改写的防复活仍无保证。
5. **没有语义重要性模型。** 修复候选截断和时间偏置，不代表能自动辨认用户所有重要记忆；同主题冲突也不具备完整时间/条件推理。
6. **大库成本待验证。** 为避免有效记录被提前截掉，现在会扫描并检查当前授权候选；本次不是长期大量数据或多进程压力测试。后续性能优化必须保留过滤优先和真实回归，不能直接恢复导致漏召回的固定前截断。
